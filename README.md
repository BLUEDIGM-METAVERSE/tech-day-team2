# 테크데이 2팀 · 영수증 OCR

영수증을 확인해 엑셀에 붙여넣고 사진을 A4로 출력하는 React·Node.js 시제품입니다. 기본은 샘플 모드이며, 서버에 Gemini 키를 설정하면 폰으로 촬영하거나 PC에서 선택한 영수증을 읽을 수 있습니다.

## 실행

Node.js 22.12 이상과 npm이 필요합니다. 저장소 루트에서 실행하세요.

```bash
npm ci
npm run dev
```

화면은 http://127.0.0.1:5173, API는 http://127.0.0.1:3001 입니다.

```bash
npm run check
npm run build
```

## Gemini OCR 실행

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 할당량을 사용할 프로젝트의 Gemini 키를 발급합니다.
2. 저장소 루트에서 `cp backend/.env.example backend/.env`를 실행합니다. `backend/.env`에 `OCR_MODE=gemini`, 발급받은 `GEMINI_API_KEY`, 프로젝트에서 이미지와 구조화 출력을 지원하는 `GEMINI_MODEL`을 입력합니다. 이 파일은 Git에서 제외됩니다.
3. `npm run dev`로 시작하거나 재시작한 뒤 `http://127.0.0.1:5173`을 열어 **Gemini 모드** 표시를 확인합니다.
4. QR로 폰에서 사진을 보내거나 PC에서 파일을 선택합니다. PC에서 작은 미리보기를 클릭하고 중앙 팝업에서 카드번호·주소 등 가릴 부분을 드래그합니다. 확대와 스크롤을 사용할 수 있습니다. 여러 영역을 가릴 수 있으며 **마지막 가림 취소**로 되돌릴 수 있습니다. 가린 사진을 확인하고 확인란에 체크한 뒤 **확인하고 닫기**를 누릅니다. **결과 불러오기**를 누르면, 브라우저가 가림을 반영한 새 PNG를 만들어 Google Gemini로 보냅니다.
5. 일자·거래처·금액을 사진과 대조해 수정한 뒤 **목록에 추가**합니다. 기존 엑셀 복사 버튼으로 확인한 행을 복사합니다.

백엔드 터미널에서 추출 시작, 추출 완료, 후처리 완료와 필드별 인식 여부를 확인할 수 있습니다. Gemini 판독 텍스트는 민감 항목 필터를 거친 뒤 백엔드 콘솔에 JSON 한 줄로 표시됩니다. 필터는 인식 가능한 라벨과 번호 형식을 기준으로 동작합니다. QR 폰 중계는 두 모드에서 사용할 수 있습니다. 마스킹과 Gemini OCR은 로컬 PC 화면에서 진행합니다. QR 사진은 마스킹 전에 폰에서 PC로 중계됩니다. [Gemini API 키 안내](https://ai.google.dev/gemini-api/docs/api-key)

## 영수증 선택과 폰 촬영

- **01 영수증 업로드 및 OCR 추출**에서는 JPG·PNG·WebP 영수증을 한 장 또는 여러 장 선택합니다. 확인 중인 영수증이 있으면 새로 고른 사진은 그 영수증을 바꾸지 않고 **대기 중인 사진**에 쌓여 한 장씩 차례로 올라옵니다. 확인 중인 영수증을 빼려면 **이미지 제거**를 누릅니다. 파일 선택, 드롭, 이미지 붙여넣기를 지원하며 긴 변이 1600px를 넘으면 브라우저에서 축소합니다.
- **샘플 결과 불러오기**는 이미지 분석 없이 고정 응답을 가져옵니다.
- PC 화면 상단의 QR을 폰으로 스캔하면 촬영 화면이 열립니다. 6자리 코드는 표시용이며, 연결에는 QR 주소의 `key`가 필요합니다.
- 폰에서 촬영하거나 **사진·파일에서 선택**으로 고른 사진은 바로 보내지 않고 폰 화면에 최대 5장까지 담습니다. 사진마다 × 버튼으로 삭제할 수 있고, **PC로 전송**을 눌러야 PC로 들어갑니다. 담긴 사진과 합쳐 5장을 넘게 고르면 하나도 담지 않고 "전송할 수 있는 이미지는 최대 5장입니다." 토스트로 안내합니다.
- 두 탭은 같은 QR 연결을 사용합니다. 가져오는 시점에 01 탭이 열려 있으면 서버에 대기 중인 사진을 모두 가져와 **대기 중인 사진**으로 표시하고, 미리보기가 비면 왼쪽 사진부터 한 장씩 올립니다. 필요 없는 대기 사진은 ×로 제거합니다. 02 탭이 열려 있으면 출력 목록에 직접 추가합니다. 받은 사진은 서버 큐에서 삭제합니다.
- 일자·거래처·금액이 모두 같은 내역이 이미 목록에 있으면 추가 전에 경고하고, 목록에서도 해당 행을 노란색으로 표시합니다. 거래처는 공백·기호·대소문자·(주)·주식회사 표기 차이를 무시하고, 한쪽 이름이 다른 쪽에 포함되어도(`KJFOOD`와 `[영수증] KJFOOD`) 같은 거래처로 봅니다. 경고만 하며 추가·복사는 막지 않습니다.
- 새로고침하면 해당 화면의 이미지·결과와 대기 사진이 사라집니다. PC를 새로고침하면 연결 코드도 새로 발급되며, 열려 있던 폰 화면은 촬영·선택 버튼을 누르거나 사진을 보낼 때 만료 안내로 바뀌므로 새 QR을 다시 찍어야 합니다. PC 화면을 열어 두지 않아 가져가지 못한 사진은 방이 만료될 때까지 서버에 남을 수 있습니다.

기본 실행은 PC 로컬 접속용입니다. 폰 연결을 시험하려면 같은 Wi-Fi에서 프런트를 LAN에 열어야 합니다. 터미널 두 개에서 각각 실행하세요.

```bash
npm run dev -w backend
```

```bash
npm exec -w frontend -- vite --host 0.0.0.0
```

API는 로컬 주소를 유지하고 Vite 프록시로 연결합니다. LAN 테스트 허용 여부는 팀 검토가 남아 있습니다.

## 영수증 배치 및 출력

1. **02 영수증 배치 및 출력**을 엽니다. 01에서 받은 사진은 마스킹 전 모습으로 자동 추가됩니다. 탭의 숫자는 01에서 업로드한 사진 수입니다. 02에서 직접 추가한 사진과 실물 부착용 빈 영역은 그 숫자에 포함되지 않습니다.
2. 02에서 파일이나 QR로 사진을 더 추가할 수 있습니다. 이 사진은 OCR을 거치지 않습니다. 미리보기에서 사진을 선택해 **잘라내기**를 누르거나 사진을 더블클릭하고, 사진 테두리의 손잡이를 안쪽으로 끌어 남길 영역을 정한 뒤 **자르기 적용**을 누르세요. 원본 전체로 되돌릴 수 있으며 OCR 마스킹에는 영향이 없습니다.
3. 미리보기에서 사진·빈 영역을 용지 위 원하는 위치로 드래그하세요. Alt+방향키로도 가로·세로로 5mm씩 움직일 수 있습니다. 직접 정한 위치는 인쇄에 반영되며, 자동 배치로 되돌릴 수도 있습니다. 미리보기 항목을 선택하면 회전·제외 또는 빈 영역 크기 조절도 할 수 있습니다.
4. 폭·간격·여백과 출력 옵션을 정한 뒤 **인쇄 / PDF 저장**을 누르세요. 인쇄 창에서 A4 세로, 배율 100%, 여백 없음, 머리글·바닥글 해제를 선택합니다. 한 장보다 긴 사진은 비율을 유지한 채 축소됩니다.

출력 사진·설정은 현재 페이지의 메모리에만 남습니다. 새로고침하거나 탭을 닫으면 사라집니다. QR로 보내고 아직 받지 않은 사진은 기존 서버 메모리 큐에 방 만료까지 남을 수 있습니다. **인쇄 / PDF 저장**에서 사용자가 선택한 출력 외에 사진 파일은 생성하지 않습니다.

## 결과 확인과 엑셀 복사

열 순서는 **일자 / 계정과목 / 비용 상세내역 / 거래처 / 금액 / 결제수단**입니다. 프로젝트경비의 마지막 열은 프로젝트번호입니다.

결과를 수정하고 **목록에 추가**하면 경비 구분별 목록에 들어갑니다. 새 행은 일자순 위치에 삽입하며, 기존 행은 수정·삭제하거나 ▲▼로 이동할 수 있습니다. 수동으로 바꾼 기존 순서는 유지합니다. 계정과목·결제수단은 제공된 목록에서 선택하고 프로젝트번호는 직접 입력합니다.

| 복사 방식 | 붙여넣는 위치와 내용 |
| :-- | :-- |
| 엑셀용 복사 (6열) | 빈 셀에 상세 값 6개를 여러 행으로 붙여넣기 |
| 원본 양식용 복사 (B~X) | 부서경비 22~36행, 프로젝트경비 46~60행 중 첫 빈 행의 B열에서 붙여넣기. B/D/G/P/S/V에 값 배치 |

- 복사 단위는 경비 구분별 목록 전체입니다. 머리글·NO·합계는 제외합니다.
- 일자·거래처와 0보다 큰 정수 금액이 있어야 목록 추가·복사가 가능합니다. 경비 구분별 15행을 넘으면 경고합니다.
- 원본 양식용 복사는 병합 폭과 서식을 담은 HTML도 함께 복사합니다. Ctrl+V로 붙여넣고, 실제 Excel·Google 시트 호환성은 양식 사본에서 확인하세요.
- 자동 복사가 실패하면 수동 복사용 텍스트를 제공합니다. 수동 복사는 병합·서식을 포함하지 않습니다.

화면 폭은 최대 1680px입니다. 1450px 이하에서는 업로드와 결과 확인 영역을 세로로 배치하며, 넓은 표는 가로로 스크롤합니다. 시트에 직접 쓰는 기능은 없습니다.

## 업로드 안정화

파일 선택 취소 시 기존 선택을 유지하고, 준비 중 상태를 안내합니다. PC 이미지 준비 중에는 폰 수신을 대기하며 새 이미지로 교체된 이전 요청 결과를 표시하지 않습니다. PNG 미리보기와 폰 전송용 JPEG 변환을 모두 지원합니다.

테스트: `node --experimental-strip-types --test frontend/tests/image.test.mjs`

## 서버·연결 안정화

API 서버가 꺼져 있거나 오류를 반환하면 화면에 안내를 표시합니다. 선택한 이미지는 유지되므로 같은 버튼으로 다시 시도할 수 있습니다. 오류 코드와 안내 기준은 [연결 계약](docs/connection.md)을 참고하세요.

테스트: `npm test -w backend`, `node --experimental-strip-types --test frontend/tests/http.test.mjs`
