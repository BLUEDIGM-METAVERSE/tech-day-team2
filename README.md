# 테크데이 2팀 · 영수증 OCR

React + TypeScript 화면과 Node.js 가짜 API로 시작하는 공통 개발 환경입니다. 실제 OCR·인증·배포는 미구현입니다.

## 실행

Node.js 22.12 이상과 npm을 사용합니다. 저장소 루트에서 실행하세요.

```bash
npm ci
npm run dev
```

첫 설치에서 lock 파일이 없는 경우에만 `npm install`을 사용합니다. 화면은 http://127.0.0.1:5173, API는 http://127.0.0.1:3001 입니다.

```bash
npm run check
npm run build
```

마스킹 샘플 이미지를 선택하면 브라우저에서 긴 변 1600px로 축소하여 미리보기합니다. 샘플 결과 버튼은 고정 응답을 가져옵니다. 이미지는 서버나 외부 AI로 전송하지 않습니다. 새로고침하면 이미지·수정값이 사라집니다.

## 지출결의서 미리보기와 엑셀 복사

샘플 결과를 원본 HTML 시안의 상세 행 순서인 **일자 → 계정과목 → 비용 상세내역 → 거래처 → 금액 → 결제수단**으로 표시합니다. 프로젝트경비로 전환하면 마지막 열은 프로젝트번호로 바뀝니다. 값을 화면에서 수정할 수 있으며, 계정과목·결제수단·프로젝트번호는 원본 목록을 확인해 직접 입력합니다.

- **엑셀용 복사 (6열)**: 수정한 값 한 행을 탭으로 구분해 복사합니다. 빈 엑셀 셀에 붙여넣으면 6개 열에 들어갑니다.
- **원본 양식용 복사 (B~X)**: B/D/G/P/S/V 열 위치에 값을 배치합니다. 부서경비는 22~36행, 프로젝트경비는 46~60행 중 빈 행의 B열에서 붙여넣습니다. 병합 셀 상태에 따라 제한될 수 있으므로 시트 사본에서 먼저 확인하세요.
- 머리글·NO·합계는 복사하지 않습니다. 자동 복사가 지원되지 않으면 수동 복사용 입력란을 제공합니다.
- 일자·거래처·금액을 확인해야 복사할 수 있습니다. 금액은 0보다 큰 원 단위 정수여야 합니다.

작업 영역은 최대 1,680px로 확장했습니다. 화면 너비가 1,450px 이하이면 업로드와 미리보기를 위아래로 배치하고, 표가 화면보다 넓으면 가로 스크롤을 제공합니다.

엑셀 복사는 클립보드 기능이며 실제 Excel·Google 시트에 자동으로 쓰지는 않습니다. 현재 결과는 가짜 API 응답이고 실제 OCR은 아직 연결되지 않았습니다.

## 담당별 시작점

| 담당 | 위치 |
| :-- | :-- |
| 업로드 화면 | `frontend/src/components/UploadPanel.tsx`, `utils/image.ts` |
| 결과 화면 | `frontend/src/components/ResultPanel.tsx` |
| 서버 연결 | `backend/src/server.mjs`, `frontend/src/services/extract.ts` |
| OCR·추출 | `backend/src/ocr/`에 모듈 추가, 공통 계약은 `docs/connection.md` |

공통 상태는 `frontend/src/App.tsx`, 데이터 타입은 `frontend/src/types/receipt.ts`에서 관리합니다.

`AGENTS.md`를 먼저 읽고 기능 브랜치에서 작업하며 팀원 1명 리뷰 후 병합합니다. 미결정 사항은 `docs/decisions.md`, AI 활용은 `docs/ai-usage.md`에 기록합니다. 키·시트 주소·실제 영수증은 커밋하지 않습니다.
