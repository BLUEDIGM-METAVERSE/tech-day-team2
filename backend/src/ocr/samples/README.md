# OCR 시험용 가짜 영수증

`receipt-NN.jpg`는 모두 지어낸 값으로 만든 이미지입니다. 실제 영수증과 카드 앱 캡처는 이 폴더에 넣지 않습니다.

- `samples.json`: 영수증별 내용과 정답(`expected`). `amount`가 `null`이면 지출 금액이 없는 전표입니다.
- `render-samples.ps1`: `samples.json`으로 이미지를 다시 만듭니다. Windows PowerShell 전용입니다.

19~21번은 카드 앱 이용내역 캡처 형식이고, 나머지는 종이 영수증 형식입니다. 컴퓨터로 그린 이미지라 실제 사진보다 인식이 쉬울 수 있으므로, 이 샘플의 정답률을 실제 영수증 성능으로 설명하지 않습니다.
