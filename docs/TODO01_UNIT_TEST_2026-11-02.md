## 검증의 한계와 남은 수동 확인

- [ ] 준비 중·요청 중 중복 조작 차단과 통신 실패 후 재시도.
- [ ] 빠른 선택의 이전 결과 무시 및 결과·오류 초기화.
- [ ] 모바일 폭·키보드·화면 낭독 안내.
- [ ] 실제 이미지로 크기·비율·방향과 새로고침 시 데이터 소멸.
- [ ] 기존 결과 편집·엑셀 복사 회귀 확인.

## 담당 3·4 인계 초안 — 전달·합의 전

현재 `resizeImage(file): Promise<string>`은 PNG data URL을 반환하며 긴 변은 최대 1600px다. 입력은 JPG·PNG·WebP, 미지원·빈 파일·손상·변환 실패는 오류로 반환한다. 실제 전송은 없고 API 계약은 바꾸지 않았다.

서버 전송에 Blob/File이 필요하면 별도 변환·함수 계약을 협의한다. 허용 용량·픽셀 제한·시간 제한·마스킹 방식은 미결정이다. 합의 전에는 미리 마스킹한 샘플을 사용하며 실제 업로드·OCR 완료로 표시하지 않는다.
