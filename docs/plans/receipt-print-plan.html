기획 검토용 · 실제 앱 연동 전
이 화면에서 체험 가능: 가상 샘플·PC 파일 추가, 썸네일 확대·잘라내기, 순서·폭 조정, A4 자동 배치, 인쇄. QR 수신과 OCR 연결은 실제 구현 단계에 연결합니다. 사진·설정은 이 페이지의 메모리에서만 사용하며 새로고침하거나 닫으면 사라집니다.

A4 출력 미리보기

01 · 모으기

업로드 즉시 출력 목록에

QR로 받은 사진과 PC 업로드 사진을 동일한 메모리 목록에 추가합니다. 마스킹하기 전 이미지가 기준이며 OCR 실패·취소 후에도 출력할 수 있습니다.

02 · 다듬기

확대해서 필요한 부분만

썸네일을 선택하면 기존 마스킹 팝업과 같은 중앙 확대창이 열립니다. 드래그로 출력할 사각형을 정하고 적용합니다. 취소하면 기존 자르기를 유지합니다.

03 · 출력하기

A4에 비율대로 자동 배치

정해진 폭과 원래 비율로 배치합니다. 한 열의 공간이 부족하면 다음 열, 다음 장으로 이동합니다. 한 장보다 긴 영수증은 통째로 축소하고 안내합니다.

출력 메뉴는 기존 OCR·목록 작업과 나란한 메뉴로 추가합니다. 메뉴를 오가도 사진과 자르기 상태가 유지되어야 합니다.

상황기획 동작
마스킹 전 사진의 정의앱이 받은 가림 없는 이미지. 현재 PC·폰 경로의 긴 변 1600px 축소는 유지하므로 원본 파일 해상도 보존과는 다릅니다. QR 사진도 PC 수신 시점의 이미지가 기준입니다.
결과 목록에 추가 / 다음 사진OCR 작업의 현재 사진은 비워도 출력용 목록은 유지합니다. 동일 이미지 처리에 receiptId를 재사용해 중복 추가를 막습니다. 사용자가 같은 파일을 새로 업로드하면 별도 항목으로 취급합니다.
자르기 팝업확대된 가림 전 이미지에 사각형을 드래그합니다. 기존 자르기 영역 표시, 다시 선택, 원본 전체 사용, 취소, 적용을 제공합니다. 작은 영역은 적용할 수 없습니다. 적용 후 썸네일·A4 배치를 함께 갱신합니다.
원본 / OCR 영향원본 픽셀은 수정하지 않고 정규화된 좌표(x, y, width, height)를 별도 보관합니다. 출력 자르기는 OCR용 마스킹·추출 결과·엑셀 목록을 변경하지 않습니다.
제외 / 순서기본은 업로드 순서. ↑↓로 출력 순서 변경, 개별 제외와 전체 비우기 제공. 출력 목록 제외는 결과 행 삭제와 독립적입니다. 다른 화면에서 참조 중인 사진은 그 참조도 없어졌을 때 해제합니다.
세션 종료사진·자르기·설정은 JS/React 메모리만 사용합니다. 새로고침·탭 닫기·브라우저 종료 시 복원하지 않습니다. localStorage, sessionStorage, IndexedDB, DB, 파일·로그 저장은 사용하지 않습니다.
QR 중계의 현재 제약현재 폰 → 서버 메모리 큐 → PC 경로입니다. 가져온 사진은 큐에서 제거되지만, 미수신 사진은 방 만료(생성 후 30분)까지 남을 수 있습니다. 브라우저 종료만으로 서버 대기가 즉시 사라진다고 보장하지 않습니다. 서버 메모리까지 금지하려면 직접 전달 방식 등 별도 중계 설계가 필요합니다.
외부 전송 / 파일 생성출력 경로에서는 원본을 서버나 외부 AI로 전송하지 않습니다. 기존 OCR은 가림을 적용한 이미지만 전송합니다. 서비스가 사진을 파일로 저장하지 않으며, 인쇄·PDF는 사용자가 요청한 브라우저 출력 동작입니다.

빈 화면과 예외

사진 0장: “QR 또는 사진 업로드로 영수증을 추가하세요” 표시, 인쇄 비활성화. 미지원·손상 파일: 해당 파일의 실패 안내 후 다른 사진은 유지. 배치 재계산 중에는 미완성 인쇄를 막습니다. 사진이 한 장보다 길면 축소 사실과 가독성 확인을 안내합니다. 수동 자르기는 사진 속 직사각형 영역 선택이며 기울기·원근 보정은 별도 범위입니다.

샘플 구조이번 기획에 반영
왼쪽 340px 설정 / 오른쪽 미리보기설정·사진 목록과 A4 용지를 분리. 좁은 화면은 세로 배치, 용지 영역은 가로 스크롤해 mm 크기를 유지합니다.
210 × 297mm 용지, 절대 좌표출력에 사용할 정확한 크기로 렌더링합니다. 조작 UI는 인쇄에서 제외하고, 마지막 장 뒤에 빈 장이 생기지 않도록 페이지 나눔을 적용합니다.
폭 / 간격 / 여백 → 열 개수 산정기본 80 / 6 / 10mm. 가용 폭 190mm에서 2열, 이미지 비율과 내부 여백을 포함해 높이를 계산합니다. 여백 안으로 폭을 제한하고 항목별 위치를 산출합니다.
열 단위 자동 배치목록 순서대로 첫 번째로 들어갈 수 있는 열에 배치. 뒤의 짧은 영수증이 앞 열의 남은 공간을 채울 수 있어, 목록 순서와 시각적 읽기 순서가 다를 수 있습니다. 페이지를 넘기면 이전 페이지로 되돌아가 채우지 않습니다.
긴 이미지 한 장 안으로 축소비율 유지, 내용 자름 없이 높이에 맞춤. 폭이 설정값보다 작아질 수 있으며 축소 항목 수를 화면에 안내합니다.
흰 여백 자동 제거초기 범위에서는 수동 자르기로 대체. 샘플의 밝기 임계값 검사는 어두운 책상·손·배경을 제거할 수 없고 내용까지 잘라낼 수 있습니다.
PDF / CDN pdf.js 로딩현재 앱의 JPG·PNG·WebP 범위를 유지. PDF 업로드·외부 CDN·새 패키지 도입은 이번 범위에 포함하지 않습니다.
회전 / 드래그 정렬초기 시안은 ↑↓ 순서 변경으로 단순화. 회전과 드래그 정렬은 후속 확장 후보이며 이번 동작 시안에는 없습니다.
빈 영역 XS~XL / 점선 / 흑백 / 파일명보조 출력 옵션으로 반영. 빈 영역은 전체 가용 높이의 1~5 단위, 사진과 같은 점선 체계입니다. 파일명은 기본 숨김입니다.
설정 localStorage 저장이번 시안에서는 제거. 설정을 포함한 전체 작업 상태를 메모리로만 관리합니다.

구현 완료 검증 기준

  • PC·QR 사진이 마스킹 전 모습으로 각각 한 번만 등록되고, OCR 성공·실패·목록 추가 후에도 출력 가능.
  • 자르기 취소 시 기존 영역 유지, 적용 시 썸네일·출력 갱신, 원본 복원 가능, OCR 마스킹·엑셀 결과에 영향 없음.
  • 58/80/95/190mm, 긴 사진·가로 사진·여러 페이지에서 겹침·페이지 경계 초과·마지막 빈 페이지 없음.
  • 사진 0장·손상 파일·반복 업로드·개별 제외·전체 비우기·새로고침에서 기대한 상태 확인.
  • 사진·작업 상태의 브라우저 저장소·DB·파일 기록 없음. 출력 경로의 네트워크 요청 없음. QR 중계 메모리의 잔여 수명은 별도 확인.
  • 브라우저 인쇄 미리보기와 실제 A4 100% 출력으로 크기·잘림·가독성 확인. npm run check / build 및 기존 OCR·엑셀 흐름 회귀 확인.
이 문서는 검토용 HTML 프로토타입입니다. 기본 사진은 Canvas로 만든 가상 영수증이며 실제 개인정보를 포함하지 않습니다.
